# БРАТВА 35 — голосовой чат

Адаптивное веб-приложение для iPhone и компьютера. Видеокамера выключена, передаётся только голос через LiveKit WebRTC.

## Что готово в проекте
- Русский интерфейс, ник и имя комнаты.
- Подключение/отключение от комнаты и управление микрофоном.
- Аудио участников через LiveKit.
- Сервер выдаёт краткоживущие токены; секрет LiveKit не попадает в браузер.
- Один Node.js-сервис раздаёт сайт и API; есть `/health`.
- Конфигурация Render Blueprint для бесплатного тестового размещения.

## Важно: приложение ещё не опубликовано
Архив — исходный код, а не готовый публичный адрес в интернете. Для настоящего голосового чата нужны два внешних аккаунта и настройка ключей: GitHub/Render для публикации и LiveKit Cloud для передачи аудио. Я не могу создать аккаунты, принять условия или подтвердить действия от имени владельца.

## Бесплатный тестовый запуск
1. Создай аккаунт на GitHub и новый пустой репозиторий.
2. Загрузи в репозиторий содержимое этой папки `bratva35` (не сам ZIP-файл).
3. Создай аккаунт на [LiveKit Cloud](https://cloud.livekit.io/) и проект на бесплатном Build-плане. В настройках проекта скопируй WebSocket URL, API Key и API Secret.
4. На [Render](https://render.com/) выбери **New → Blueprint**, подключи репозиторий и подтверди создание сервиса `bratva35`.
5. В Render → Environment добавь переменные:
   - `LIVEKIT_URL` — URL проекта LiveKit (обычно начинается с `wss://`)
   - `LIVEKIT_API_KEY` — API Key
   - `LIVEKIT_API_SECRET` — API Secret
6. Дождись успешного Deploy. Открой адрес Render; проверка `https://ТВОЙ-АДРЕС/health` должна вернуть `{"ok":true,"app":"БРАТВА 35"}`.
7. Открой адрес сайта в Safari на iPhone и в браузере на ПК. Введи ник и одинаковое имя комнаты на обоих устройствах, нажми «Войти в голос» и разреши доступ к микрофону.

**Не отправляй API Secret в чат и не добавляй его в файлы клиентской части.** Добавляй ключи только в Environment на Render. Не подключай платный тариф и не вводи платёжные данные, если хочешь остаться в рамках бесплатного теста.

## Ограничения бесплатного размещения
Бесплатный Render Web Service засыпает после 15 минут без входящего трафика и может просыпаться около минуты; бесплатные сервисы также имеют лимиты ресурсов. LiveKit Cloud Build включает квоты на WebRTC, одновременные подключения и трафик; при исчерпании квот новые подключения могут перестать работать до сброса лимита. Условия провайдеров меняются, проверяй их панели перед запуском.

## Локальный запуск (Node.js 20+)
```bash
npm install --prefix server
npm install --prefix client
npm run build --prefix client
```
Создай `server/.env` по образцу `.env.example`, заполни три переменные LiveKit, затем:
```bash
npm start --prefix server
```
Открой `http://localhost:3001`.
